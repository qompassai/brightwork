# brightwork

Brightwork is a local-first still-image finishing library in Rust: matting, inpainting, and face finishing behind a provider trait, with a hash-pinned ONNX model manager. It is built to embed as finishing tools inside media producers — Superpose embeds it as its still-image finishing stage.

## Status

The crates.io name `brightwork` was claimed on 2026-10-25 at version 0.1.0 with the name-reservation crate seeded here. The library itself is under construction in its build tree and lands in this repository as it is built; the in-tree rename of the build tree to brightwork is a separate step. What is in this repository today is the reservation crate, the license, and this note — not the finished library.
